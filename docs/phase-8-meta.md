# Phase 8 — 永続進行(筋力コア・アンロック・強化)

## 目的

「日を跨いで積み上がる」メタ進行を実装し、毎日運動する動機を作る。

## 前提

Phase 7 完了(1ランが完全に成立する)。

---

## 1. 筋力コア

| コア | 種目 | 対応カテゴリ |
|---|---|---|
| 胸コア `chest` | 腕立て伏せ | ATTACK |
| 脚コア `leg` | ジャンプスクワット | SKILL |
| 捻転コア `twist` | ツイストレッグレイズ | DEBUFF |
| 体幹コア `core` | プランク(2秒=1カウント) | POWER |

### 付与式
```
cores = min( floor(count / 10), 5 )      // 種目ごと
```
`× D.coreMult` を適用(ふつう1.0 / むずい1.2)して `floor`。

例(むずい・プランク120秒): `count=60` → `min(6,5)=5` → `floor(5*1.2)=6` コア

### 付与タイミングと敗北ペナルティ

**ラン終了時(クリア・敗北を問わず)に付与**。ただし敗北時は **50%没収**。

```js
// 種目ごとに算出したあと、最後に生存判定を掛ける
let v = Math.floor( Math.min(Math.floor(count/10), 5) * D.coreMult );
if (!cleared) v = Math.ceil(v * 0.5);      // 敗北時は50%没収(端数は切り上げ=プレイヤー有利)
```

- 端数は **切り上げ**。1コアが0にならないようにする(0回の種目は元々0なので影響しない)
- 例(ふつう・腕立て50回): クリア `5コア` / 敗北 `3コア`
- 例(むずい・プランク120秒): クリア `6コア` / 敗北 `3コア`
- VICTORY / GAMEOVER 画面で `+胸コア5 +脚コア3 …` を演出付きで表示。
  GAMEOVER では `胸コア 5 → 3(-50%)` のように**没収前後を両方**見せる
- 1日1回制限は設けない(何度でも遊べる)が、`meta.lastPlayDate` は記録しておく

## 2. 強化所(META画面)

タイトルから入る。4つのタブ。

### 2.1 カードプール拡充
初期状態では **COMMON のみ解禁**。UNCOMMON / RARE は購入してアンロックする。

| 対象 | コスト |
|---|---|
| UNCOMMON カード 1種 | 対応コア **8** |
| RARE カード 1種 | 対応コア **20** |

- カテゴリごとに対応コアを消費(ATTACK なら胸コア)
- アンロック済カードのみ Phase 1 のデッキ生成 / Phase 6 の報酬・ショップの候補に入る
- **`meta.unlocked` が空でもゲームが成立する**こと(COMMON だけで回る)

> ⚠️ Phase 1〜7 では「全カード解禁」で実装していたはず。ここで `isUnlocked(cardId)` を
> 全ての抽選箇所(`rollCardOf` / `pickRewardCards` / ショップ在庫 / イベント報酬)に通す。

### 2.2 初期デッキの Upgrade 差し替え
BASIC 4種(`atk_punch` `pwr_guard` `skl_sidestep` `dbf_feint` + `atk_double_punch` `pwr_brace`)を
恒久的に `+` 版にする。

| 対象 | コスト |
|---|---|
| BASIC 1種 | 対応コア **12** |

購入すると `meta.upgradedBasics` に追加。以降の全ランで初期デッキが `+` になる。

### 2.3 レリックプール拡張
初期は `rel_training_proof` `rel_unyielding_plate` `rel_accelerator` の3種のみ出現。
残り3種を **各コア 15**(任意のコアから支払い可)でアンロック。

### 2.4 難易度解放
- **「むずい」は初期状態ではロック**。ふつうを1回クリアすると解放
- `meta.clearedNormal` フラグを VICTORY 時に立てる
- 解放条件をタイトル/難易度選択画面に明示する

## 3. 強化所UI

- 上部に4種のコア所持数を大きく表示
- タブ切替。各項目はカード/レリックのプレビュー付き
- 購入可能(コア足りる)= 明るく、不足 = グレー + 不足数表示
- 購入は確認ダイアログ経由(誤タップ防止)。**取り消し不可**を明記
- 「リセット」ボタン(デバッグ時のみ表示)

## 4. 実装する関数

```js
function grantCores(run)              // ラン終了時。meta.cores に加算し、獲得内訳を返す
function isUnlocked(cardId)           // BASIC/COMMON は常に true
function unlockCard(cardId)           // コア消費してアンロック
function upgradeBasic(cardId)         // コア消費して meta.upgradedBasics へ
function unlockRelic(relicId)
function relicPool()                  // 解禁済レリックのみ返す
function costOf(kind, rarity)         // → コア数
```

## 5. 完了条件

- [ ] ラン終了(勝敗どちらでも)でコアが加算され、リロード後も残る
- [ ] プランク120秒・むずいで、クリア時に体幹コアが 6 入る
- [ ] 同条件で**敗北**時は 3 に半減し、GAMEOVER 画面に `6 → 3` と表示される
- [ ] 敗北時に 1 コアが 0 にならない(切り上げ)
- [ ] 強化所で UNCOMMON カードをアンロックすると、次のランのデッキ生成・報酬に出現する
- [ ] 未アンロックの UNCOMMON / RARE が報酬・ショップ・生成のどこにも出ない
- [ ] BASIC を Upgrade 差し替えすると、次のランの初期デッキが `パンチ+` になる
- [ ] レリック未解禁の3種が宝箱・ショップに出ない
- [ ] 初回起動時「むずい」がロックされており、ふつうクリアで解放される
- [ ] コアが足りない購入がブロックされる
- [ ] セーブを消して再起動すると初期状態(COMMON のみ)から始まる
- [ ] `meta` のみが永続され、`run` は完走/敗北でクリアされる
