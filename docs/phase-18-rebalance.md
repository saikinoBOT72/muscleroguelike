# Phase 18 — 3幕構成での再調整と最終QA

## 目的

Phase 11〜17 で作った全要素を、3幕構成のもとで測り直して調整する。
**運動量とクリア率が単調増加すること**を最優先で守る。

## 前提

Phase 11〜17 完了。

---

## 1. 測定

`docs/balance-log.md` の Phase 9 と同じ手法(ヘッドレスブラウザ + 簡易AI + 200ラン/条件)。
AI は以下を新要素に対応させる。

| 要素 | AI の方針 |
|---|---|
| ポーション | 「今ターンの被ダメ見込み > 現HPの40%」なら防御系、敵HP合計が低ければ攻撃系を使う |
| 呪い | 除去の優先度を最高にする(ショップ・イベント) |
| ボスレリック | Energy+1 系を最優先で取る |
| 祝福 | 「見識」(RAREカード)を選ぶ |
| 幕移動 | HP が50%未満なら REST を優先(既存のまま) |

### 測定条件

| 条件 | 運動量(1種目) |
|---|---|
| 0回 / 25回 / 50回 / 100回 / 200回(全種目均等) | ふつう・むずいの2軸 |
| **1種目のみ200回**(押しの型 / 支えの型) | ふつう・むずいの2軸 |
| **2種目のみ100回** | ふつうのみ |
| 初期セーブ / 全開放 | ふつうのみ |

---

## 2. 目標値

| 指標 | ふつう | むずい |
|---|---|---|
| クリア率(シミュレーション) | 45〜60% | 15〜25% |
| 第1幕クリア率 | 85%以上 | 60%以上 |
| 第2幕クリア率 | 65%以上 | 35%以上 |
| ボス到達時HP | 40〜70% | 25〜50% |
| 最終デッキ枚数 | 28〜40枚 | 28〜40枚 |
| **運動0回 と 各種目100回 のクリア率差** | **25ポイント以上** | **25ポイント以上** |
| **1種目特化(200回×1)と 均等(50回×4)** | 均等が10〜25ポイント上 | 同左 |

最後の2行が最重要。

- **運動量とクリア率が単調増加すること。** Phase 9 で一度これが 0 になり、根幹が壊れていた
- **偏った運動より均等な運動のほうが強いこと。** 2.2章「深さ」が効いていれば自然にそうなる。
  1種目特化が均等より強い場合、深さの制限が緩すぎる

調整するたびに両方を必ず確認し、`docs/balance-log.md` に記録する。

### 調整の優先順位

1. `ACT_SCALE` の幕倍率
2. `DIFFICULTY` の難易度倍率
3. 幕別の敵プールと編成
4. ポーションのドロップ率
5. カード個別の数値(最後の手段。変更したら `docs/upgrade-sts.md` も更新する)
