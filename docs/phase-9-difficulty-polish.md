# Phase 9 — 「むずい」の仕上げ・バランス調整・演出

## 目的

各フェーズで断片的に入れてきた難易度差を**検証・調整**し、演出とUXを整えて完成させる。

## 前提

Phase 8 完了(全機能が実装済み)。

**追加(このフェーズで新規実装)**:
- 戦闘開始時、**初期デッキの `パンチ` 1枚が「疲労」カードに置き換わらない**(=呪いカードは導入しない)。
  むずいの厳しさは敵性能側のみで表現し、デッキ汚染は入れない
- ボス戦は**2連戦**にはしない(1体のまま)。ラン全体の長さは変えない

> 設計方針: 報酬倍率を 1.2 に抑えているぶん、むずいは「難しいのに旨味は少し」というストイックな
> やり込み枠。ここを 1.5 倍などにするとふつうを遊ぶ理由が消えるので上げないこと。

## 2. バランス検証(必須)

実際に **各難易度3ラン以上**プレイして、以下を記録・調整する。

| 指標 | 目標値(ふつう) | 目標値(むずい) |
|---|---|---|
| Row1 の通常戦の被ダメージ | 0〜8 | 5〜15 |
| ボス到達時のHP残量 | 40〜70% | 20〜50% |
| クリア率(体感) | 60〜70% | 25〜35% |
| 1ランの所要時間 | 15〜25分 | 15〜25分 |
| 最終デッキ枚数 | 15〜25枚 | 15〜25枚 |

### 調整の優先順位
1. 数値が外れていたら **`DIFFICULTY` の倍率**を触る(1箇所で済む)
2. それでも駄目なら **エンカウントテーブル**(`ENCOUNTERS`)の編成を変える
3. カード個別の数値は最後の手段(仕様書からの乖離になるので、変更したら `spec-master.md` も更新する)

**調整結果は `docs/balance-log.md` に「変更前→変更後→理由」で必ず記録すること。**

## 3. 演出・UX の仕上げ

### 3.1 戦闘演出
- ダメージ数値のポップアップ(赤=被弾、白=与ダメ、青=ブロック)
- 被弾時に画面を短くシェイク(80ms)。連打時は重ねない
- カード使用時のスライドアウト
- 敵の攻撃モーション(前後に軽く動く 200ms)
- HPバーの減少をトゥイーン(200ms)
- **全アニメーションを一括OFFにできる設定**を用意(`meta.settings.reduceMotion`)

### 3.2 敗北時の心理設計(仕様書11章の宿題)
GAMEOVER 画面で以下を必ず表示:
1. `到達: Row X / 撃破: N体` の実績
2. **獲得した筋力コアの内訳**(`5 → 3` と没収前後を並べ、半分は残ることを強調)
3. 救済メッセージ(ランダムに1つ):
   - `倒れた回数だけ、明日の筋肉になる。`
   - `今日の運動は無駄にならない。半分は持ち帰った。`
   - `デッキが弱かったんじゃない。回数が足りなかっただけだ。`
4. 「もう一度挑む」ボタン(運動入力画面へ直行、同じ入力値をプリセット)

**筋力コアは50%没収**(仕様書6章どおり)。ただし端数は切り上げ、内訳は没収前後を両方表示し、
「ゼロにはならない」ことが一目で分かる見せ方にする。ペナルティは残しつつ、
現実の運動が無駄になったと感じさせないのがこの画面の役割。

### 3.3 その他
- カードの説明ツールチップ(長押し/右クリック)
- 山札・捨て札・除外の中身をいつでも確認できる
- 「ターン終了」の誤タップ防止(手札にコストを払えるカードが残っている場合のみ確認ダイアログ)
- 設定画面: アニメーションOFF / セーブデータ削除 / 音量(音を入れるなら)
