# 筋トレ融合ローグライク

その日の筋トレ回数がそのままデッキになる、ターン制カードバトル・ローグライク。

- **腕立て伏せ** → ATTACK(攻)
- **ジャンプスクワット** → SKILL(速)
- **ツイストレッグレイズ** → DEBUFF(崩)
- **プランク** → POWER(耐)

## 実装

単一ファイル `index.html`(HTML + CSS + Vanilla JS、ビルド不要)。

実装は `docs/README.md` に記載の **Phase 0 〜 Phase 9** の順に進める。

- [`docs/README.md`](docs/README.md) … フェーズ一覧・アーキテクチャ・進め方
- [`docs/spec-master.md`](docs/spec-master.md) … 完全仕様書(正典)
- `docs/phase-*.md` … 各フェーズの実装指示書
