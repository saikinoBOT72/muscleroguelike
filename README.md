# 筋トレ融合ローグライク

その日の筋トレ回数がそのままデッキになる、ターン制カードバトル・ローグライク。

- **腕立て伏せ** → ATTACK(攻)
- **ジャンプスクワット** → SKILL(速)
- **ツイストレッグレイズ** → DEBUFF(崩)
- **プランク** → POWER(耐)

## 遊び方

`index.html` をブラウザで開くだけ。ビルドもインストールも不要です。

1. ラン開始 → 難易度を選ぶ(最初は「ふつう」のみ。1回クリアで「むずい」解放)
2. その日の運動記録を入力する — 回数がそのままデッキになる
3. 分岐マップを進み、カードバトルでボスを目指す
4. ラン終了時に筋力コアを獲得(敗北時は50%没収)。強化所で恒久的に強くなる

**回数が多いほど、カードの枚数だけでなくレアリティ・強化・毎ターンの手札枚数も増えます。**
